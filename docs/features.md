## 二、未来计划功能

### 2.1 第一优先级 （短期）

| 功能 | 复杂度 | 预计时间 | 说明 |
|------|------|------|------|
| JWT 鉴权与用户隔离 | 中 | 2-3天 | 当前 DEV_USER_ID 替换为真实用户鉴权 |
| 简历去重检测增强 | 低 | 1天 | 利用 pgvector 向量相似度检测重复简历 |

| Toast 持续时间可配置 | 低 | 0.5天 | 支持自定义消失时间 |

### 2.2 第二优先级 （中期）

| 功能 | 复杂度 | 预计时间 | 说明 |
|------|------|------|------|
| 语音面试 | 高 | 5-7天 | WebSocket + 百炼 ASR/TTS，实时语音交互 |
| AI 日程解析 | 中 | 2天 | 解析面试通知邮件/快照，自动添加日程 |
| 多语言支持 | 中 | 2天 | 英文 / 日文界面切换 |
| 黑暗模式 | 低 | 1天 | 主题切换 |

### 2.3 第三优先级 （长期）

| 功能 | 复杂度 | 说明 |
|------|------|------|
| 面试录制与回放 | 高 | 录制整个面试过程，支持回放 |
| 面试对打模式 | 高 | 多人实时面试 |
| 职位匹配度分析 | 中 | 简历与岗位 JD 组合分析 |
| 面试素材库 | 中 | 社区共享面试经验 |
| Docker 容器化部署 | 中 | 提供完整的 Docker 部署方案 |
