## 〇、与真实可应用项目的差距评估

> 定位：功能完整度已达"可用的个人求职辅助工具"（简历→面试→报告→回顾闭环可用）。
> 要成为"真实可应用项目"，按以下优先级补齐：

### P0 - 上线底线（安全/稳定性/数据安全）

| # | 差距 | 现状 | 建议 |
|---|------|------|------|
| 1 | 多用户数据隔离测试不足 | 鉴权按 user_id 隔离已实现 | 补多账号并发测试（简历/面试/知识库互不可见） |
| 2 | 文件上传安全校验 | 仅校验扩展名与大小 | 校验文件魔数（PDF %PDF / DOCX PK），防伪装文件 |
| 3 | AI 输出安全 | 简历文本直接拼入 prompt | 长度限制 + 敏感词过滤 + LLM 输出 JSON schema 校验 |
| 4 | 数据库备份 | 无自动备份 | pg_dump 定时备份 + uploads/ 备份策略 |
| 5 | 日志可观测性 | 仅 console/journalctl | 结构化日志聚合 + 关键错误告警 |

### P1 - 上线前应解决（体验/完整性）

| # | 差距 | 现状 | 建议 |
|---|------|------|------|
| 6 | SSE 断线恢复 | answer-stream 已做请求级重试 | 基于 session 的消息重放，断线恢复现场 |
| 7 | 报告 PDF 中文样式 | 存在中文样式问题 | 完善中文字体嵌入与布局 |
| 8 | 知识库批量管理 | 仅单文档删除 | 多选删除 + 相似文档查重 |
| 9 | 简历删除级联 | 关联面试记录残留 | 删除简历时级联处理关联会话 |
| 10 | AI 服务降级 | 超时直接报错 | 超时重试 + 友好降级提示 |
| 11 | Token 过期处理 | 401 无统一跳转 | 401 自动清除登录态跳登录页 |

### P2 - 增强（竞争力/差异化）

| # | 差距 | 现状 | 建议 |
|---|------|------|------|
| 12 | 语音面试 | InterviewType.VOICE 已预留 | WebSocket + 百炼 ASR/TTS |
| 13 | 多角色面试官 | 单一面试官 | 技术深挖/行为 STAR/压力面试官可切换 |
| 14 | 追问链 | 单轮反馈后切题 | 按回答关键词自动 2-3 层追问 |
| 15 | 简历语义去重 | 仅 content_hash 精确去重 | 向量相似度去重 |
| 16 | 数据统计看板 | 首页基础概览 | 面试趋势、弱项雷达、进步曲线 |
| 17 | 移动端适配 | 桌面优先 | 完善移动端布局 |

### P3 - 远期（规模化）

| # | 差距 | 建议 |
|---|------|------|
| 18 | 对象存储（MinIO/S3） | 支持多实例部署 |
| 19 | 限流与防刷 | API 限流（登录/上传/AI） |
| 20 | 多租户/组织 | 团队共享知识库与面试模板 |
| 21 | 国际化 | i18n 多语言 |
| 22 | 通知提醒 | 面试日程邮件/微信提醒 |
